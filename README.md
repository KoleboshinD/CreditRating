<h1 align="center">
  CreditRating
</h1>

**MoneyLand** — это веб-приложение для управления кредитными заявками и мониторинга кредитного рейтинга пользователя. Сайт помогает пользователям оценить свои шансы на получение кредита в разных банках и получить персональные рекомендации.

---

##  Структура проекта

Проект состоит из 4 основных страниц:

- **Авторизация** (регистрация нового пользователя)
- **Вход** (аутентификация существующего пользователя)
- **Главная страница** (основной функционал)
- **Профиль пользователя** (личные данные и кредитная история)

---

## Функционал проекта

### Главная страница

На главной странице пользователь может:

- **Проверить кредитный рейтинг** в выбранном банке.
- **Отправить запрос на кредит**.
- **Получить результат обработки запроса**:
  - При одобрении / отказе отображаются списки банков, которые **одобряют** или **не одобряют** кредит.
- **Получить рекомендации** по повышению кредитного рейтинга.

### Страница профиля пользователя

На странице профиля отображается:

- **ФИО и контактные данные** клиента.
- **Текущий кредитный рейтинг** пользователя.
- **История кредитов**:
  - Действующие кредиты.
  - Закрытые (погашенные) кредиты.
